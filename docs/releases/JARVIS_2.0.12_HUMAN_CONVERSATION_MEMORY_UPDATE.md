# JARVIS 2.0.12 — Natural Conversation & Fast Memory Update

## Scope
This release updates the existing Gemini Live conversation path, memory context assembly, wake-word greeting instruction, and end-of-speech timing. It does not replace the wake-word engine, audio stack, command tools, or existing Room schema.

## Wake-word activation contract
- On a wake-word activation, the service sends one explicit wake-greeting instruction: output exactly `Yes Boss.` and nothing else.
- The activation turn must not add a follow-up question, status message, proactive suggestion, reminder, or wellbeing nudge.
- Pending reminders and wellbeing prompts are not injected immediately after the wake greeting. They remain managed by their existing delivery paths.
- The greeting is not repeated during the active session.
- If the user begins speaking during the connection handshake, the existing speech-detection guard may suppress the greeting to avoid talking over the user.

The wake greeting is still generated by the configured Gemini Live voice after the Live session is ready. It is not a locally pre-rendered audio clip; network/model latency can therefore affect its start time.

## Conversation behavior
The feminine companion persona now explicitly prioritizes conversational intent and continuity:
- Interpret context, teasing, sarcasm, indirect requests for attention, sulking, and reassurance-seeking without assuming every phrase is literal.
- Ask one short clarification when intent is genuinely ambiguous; do not invent an explanation or a past event.
- Respect a clear request to stop or a real boundary. A playful/sulking "I don't want to talk" may receive one gentle response, but must not trigger pressure or repeated pursuit.
- Carry the emotional state of an apology, disagreement, joke, or affectionate exchange into the next turn.
- Use laughter, interjections, and expressive wording only when the moment supports them. Never add laughter to serious or sad moments just to sound lively.
- Vary response shape and avoid repeated pet names, stock apologies, repeated questions, and scripted punchlines.
- Keep ordinary voice replies concise and task execution accurate and restrained.

## Memory and latency
- The full local chat history remains persisted by the existing ChatRepository; this patch does not delete or migrate the transcript.
- The Gemini system context now sends a bounded memory snapshot: profile fields, up to 24 newest Room facts, up to 8 recent exchanges, and a compact cue string derived from older user messages.
- Older conversation cues are context hints, not a verbatim transcript. Recent exchanges take priority over older cues.
- The assembled context is cached in memory for up to 60 seconds. Known memory-learning, explicit remember/forget, song-play, and short-term-turn updates invalidate the cache.
- This avoids replaying the full conversation archive into the model on every new session while retaining enough continuity for common follow-ups.
- The cache is process-local. Persistent facts and chat history remain stored using the existing local storage mechanisms.

## Turn-taking
The Gemini Live automatic end-of-speech silence threshold is reduced from 1500 ms to 950 ms to reduce unnecessary response delay. This is a latency/turn-taking trade-off: very short pauses inside a sentence may be more likely to end an utterance early on some microphones/noisy environments. Tune this value on the target device if needed.

## Suggested device QA
1. Activate by `Jarvis` and `Hey Jarvis`: hear only `Yes Boss.`
2. Stay silent for 10 seconds: JARVIS must not add a second sentence.
3. Speak a follow-up: JARVIS should respond without an unnecessary long pause.
4. Discuss a detail, end the session, reactivate, and ask about it: recent dialogue should be available when included in stored chat history.
5. Save a fact explicitly, restart the app, and ask about it.
6. Have a multi-turn emotional exchange and check that the next response does not reset the mood or repeat the same canned line.
7. Test short natural pauses and noisy-room speech to ensure the 950 ms threshold does not clip normal sentences.
